# AidenDuncanPortfolio

## Web and Scripting Programming Assignment

The main goal of this website is to create a personal portfolio that introduces myself while showcasing some of the knowledge and skills I have developed throughout my studies in Networking and IT Security.

I used Express.js, Node.js, and EJS to develop the website, along with HTML, CSS, and Bootstrap to create its layout and appearance.

## Navigation

I included a navigation bar that allows visitors to easily move between the different pages of the website.

The navigation bar contains four sections: Home, About Me, Projects, and Contact Me. I used Bootstrap to style the navigation bar and maintain a consistent appearance throughout the website.

## Page Design and CSS

I chose a simple colour scheme consisting mainly of white, dark navy, and blue. I wanted the website to have a clean and modern appearance while keeping the content easy to read.

Most of the styling is contained in `style.css`, while Bootstrap is used to help organize the layout and make the website responsive across different screen sizes.

I also used Font Awesome to include icons throughout the website, particularly in the navigation bar, project sections, and footer.

## Main Page

The Home page acts as the introduction to my portfolio. I included a welcome message introducing myself as a Networking and IT Security student, along with some of my main areas of interest.

I also included a button that directs visitors to the Projects page.

## About Me

The About Me page provides more information about my background, education, and technical interests.

I included information about my studies in Networking and IT Security, as well as my interests in networking, cybersecurity, and web development. I also included some of my future career goals.

## Projects

The Projects page showcases some of the work I have completed throughout my studies.

The projects include a personal portfolio website, networking lab projects, JavaScript applications, and an economic project examining consumer demand for a hardware business.

I used Bootstrap cards and images to organize the projects and make the page easier to navigate.

## Contact Me

The Contact Me page contains a simple contact form where visitors can enter their name, email address, and a message.

I used different HTML input types, including text and email, as well as a textarea for longer messages.

## Express and EJS

I used Express.js to manage the different routes throughout the website. Each route renders its corresponding EJS page.

I also used EJS partials to avoid repeating the same HTML across multiple pages. The header, navigation bar, and footer are stored separately and included throughout the website.

This makes the website easier to maintain and keeps the layout consistent across all four pages.

## Overall Goal

Overall, I wanted to create a simple personal portfolio that introduces myself while showcasing some of the academic projects and technical skills I have developed.

The website demonstrates my understanding of Express.js, EJS, HTML, CSS, Bootstrap, and responsive web design. I also wanted to keep the website organized, visually consistent, and easy for visitors to navigate.
